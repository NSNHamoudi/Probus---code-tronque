# Probus---code-tronque

Le reposotory présent contient des extraits (tronqués) du code source de l'outil Probus, développé à l'Institut national de l'audiovisuel(INA) dans le cadre d'un stage de fin d'année du M2 TNAH de l'École nationale des chartes.

Ces extraits ont  été partagés avac l'accord de l'INA, et n'ont vocation qu'à servir à  l'évaluation de ce stage et du mémoire qui en a découlé.

## Attention : Ce code n'est pas exécutable en l'état, ni en dehors de l'INA, et les extraits ici-présents ne sont partagés que dans une finalité académique.
