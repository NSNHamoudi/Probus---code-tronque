# Probus---code-tronque

Le reposotory présent contient des extraits (tronqués) du code source de l'outil Probus, développé à l'Institut national de l'audiovisuel dans le cadre d'un stage de fin d'année du M2 TNAH de l'École nationale des chartes.

Ces extraits de code sont publiés dans le cadre de l'évaluation de ce stage et du mémoire qui en a découlé.

## Attention : Ce code n'est pas exécutable en déhors de l'INA
